# База

`001_init.sql` создаёт структуру для новой пустой базы. Он не удаляет и не переносит существующие данные. Если `public.leads` уже существует, не запускайте его поверх рабочего проекта.

`002_restrict_public_access.sql` оставляет доступ через серверное подключение: включает RLS, отзывает права публичных ролей и выполнение enqueue-функции публичными ролями Supabase. Запускайте от владельца таблицы. В рабочем проекте эта миграция уже применена.

Ни один из файлов не содержит пароль, URL подключения или данные заявок. Для новой установки используйте приватное серверное подключение n8n. Публичные browser credentials Supabase для этого маршрута не нужны.
